# 装修材料学习

装修材料学习的重点不是背品牌，而是建立完整判断链：

**基材 → 胶黏体系/环保等级 → 饰面 → 封边 → 品牌/系列 → 实际交付与验收**

## 已覆盖

- 水电基础：电线、回路、L/N/PE、漏电保护、空开、配电
- 水路、防水与地暖
- 板材、基材、胶和封边
- 瓷砖与美缝
- 油工、基层与乳胶漆
- 门窗、吊顶、石材和踢脚线
- 套餐预算、清单预算和报价边界
- CAD、面积、周长、墙高和墙面积

## 重要判断

- 品牌不等于型号，型号不等于施工工艺，施工工艺也不等于最终验收结果。
- 公司资料里的品牌、规格和价格，只代表对应资料和时间范围内的配置事实。
- 套餐预算和清单预算不能交叉套价。
- 精确价格、型号和规格要回查原始预算或合同。
- 未明确支持的细节保持 UNKNOWN。
