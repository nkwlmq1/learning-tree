# 板材与柜体

板材判断链：基材 → 胶黏体系/环保等级 → 饰面 → 封边 → 品牌/系列 → 实际交付与验收。

资料中出现 ENF、E0、实木颗粒板、欧松板、生态板和双筋板等信息。它们属于不同维度，不能混成单一排名。

验收时分别核对柜体、门板、背板、封边、裸露基材、送货单和对应批次检测资料。看到一处基材不能推断整柜所有构件。

下一步：继续补胶黏体系、封边工艺和品牌横向比较。
